# Tháp Hà Nội

Trò chơi Tháp Hà Nội chạy trên trình duyệt: chọn đĩa, chuyển sang cột C, đếm bước, bấm giờ và xem máy giải.

## Chơi local

Mở `index.html` trong trình duyệt, hoặc phục vụ thư mục này bằng bất kỳ HTTP server tĩnh nào.

## GitHub Pages

Repo được cấu hình để publish từ nhánh `main`, thư mục gốc.
